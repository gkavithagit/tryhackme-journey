🔐 Key Concepts Learned

1. Offensive Security

Offensive Security focuses on taking an attacker's perspective to identify weaknesses in systems, networks, applications, and other digital assets.

The objective is not to cause damage, but to discover vulnerabilities so they can be fixed before malicious attackers exploit them.

2. Ethical Hacking

Ethical hacking involves legally and responsibly testing systems for security weaknesses.

An ethical hacker works within an authorized scope and follows defined rules while performing security testing.

3. Attacker Mindset

One of the most important concepts I learned is the importance of thinking like an attacker.

Instead of only asking:

«"How does this system work?"»

A security professional also asks:

«"How could this system be misused or attacked?"»

This mindset is important for identifying weaknesses that may not be obvious during normal system usage.

4. Penetration Testing

Penetration testing is a controlled security assessment in which authorized testers attempt to identify and validate vulnerabilities in a system.

A typical penetration-testing process can involve:

Reconnaissance → Enumeration → Vulnerability Identification → Exploitation → Analysis → Reporting

Understanding this workflow gives me a foundation for learning more advanced penetration-testing techniques.
