🎯 Learning Objectives

The objective of this room was to understand the fundamentals of defensive security and how security professionals help protect systems, networks, and data against cyber threats.

📚 Key Concepts Learned

1. What Is Defensive Security?

Defensive security focuses on protecting digital assets by identifying threats, monitoring systems, investigating suspicious activities, and reducing security risks.

2. Security Operations Center (SOC)

A Security Operations Center (SOC) is a team or function responsible for monitoring security events, investigating potential incidents, and coordinating responses to threats.

3. Threat Intelligence

Threat intelligence involves collecting and analysing information about cyber threats to understand attacker behaviour and help organisations improve their defences.

4. Digital Forensics and Incident Response

- Digital Forensics: Examining digital evidence to understand what happened during a security incident.
- Incident Response: Detecting, analysing, containing, and recovering from security incidents.

5. Defensive Security in Practice

Defensive security professionals help organisations identify suspicious activity, investigate alerts, understand potential attacks, and strengthen their security controls.
