🎯 Learning Objectives

The objective of this room was to understand the fundamental components of a computer system and how they work together to execute instructions and process data.

📚 Key Concepts Learned

1. Central Processing Unit (CPU)

The CPU is responsible for executing instructions and processing data. It performs calculations, controls operations, and coordinates tasks within the computer.

2. Random Access Memory (RAM)

RAM temporarily stores the data and instructions that the CPU needs while programs are running. It is volatile memory, meaning its contents are generally lost when the computer is powered off.

3. Storage Devices

Storage devices, such as HDDs and SSDs, retain data, applications, and operating system files even when the computer is turned off.

4. Motherboard

The motherboard connects the CPU, RAM, storage devices, and other hardware components, allowing them to communicate with one another.

5. Input and Output Devices

Input devices provide data to the computer, while output devices present the results of processing.

Examples:

- Input: Keyboard and mouse
- Output: Monitor and speakers

6. How Computer Components Work Together

A computer system operates through cooperation between hardware and software. Programs and data are loaded into memory, the CPU processes instructions, and the system produces results or stores information.

🔐 Cybersecurity Relevance

Understanding computer architecture is important in cybersecurity because security professionals need to know how computer systems operate before investigating vulnerabilities, analyzing malware, troubleshooting systems, or understanding attacks.

These fundamentals provide a foundation for learning operating systems, system security, digital forensics, and incident response.
